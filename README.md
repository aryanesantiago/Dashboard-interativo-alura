📊 Dashboard de Salários na Área de Dados

Este projeto é um dashboard interativo desenvolvido em Python com Streamlit, permitindo explorar dados salariais na área de dados de forma visual e dinâmica.

✨ Funcionalidades

• 📅 Filtros interativos por ano, senioridade, tipo de contrato e tamanho da empresa.

• 📈 Gráficos interativos usando Plotly: barras, histograma, pizza e mapa mundial.

• 💰 Métricas gerais: salário médio, salário máximo, total de registros e cargo mais frequente.

• 🗂️ Visualização detalhada dos dados filtrados em tabela.

🛠️ Tecnologias

• Python 3

• Streamlit

• Pandas

• Plotly
